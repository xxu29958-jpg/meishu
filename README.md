# Review images for atlas-europe-01

Not for merging. These are pictures of the batch `submissions/atlas-europe-01` on branch `art/atlas-europe-01`, kept apart so that branch declares every PNG it holds.

- `01-europe-whole-map.png`: the thirty delivered chunks assembled, reduced to 1500 px.
- `02-close-ups-actual-size.png`: eight windows at delivered size.
- `03-in-play-120km-hex.png`: mock-up with towns and troops from campaign-atlas-01 on the decided 120 km grid, shown faintly.
- `04-hex-terrain-table.png`: the derived terrain table tinted over the map at half size. Blue dots: hexes a major river runs through. Red rings: small places kept as land. Yellow squares: strait passages.
- `05-details-3x.png`: the Zuiderzee, the Sea of Marmara, the Nile delta and the Strait of Messina, enlarged three times.
