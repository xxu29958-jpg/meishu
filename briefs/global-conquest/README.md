# 全球视觉内容接口

独立身份 global-visual.v1，start_year 只是历史主题上下文。entities 描述政治实体的显示名称、旗帜资源、地图颜色、特色兵种、历史人物和建筑风格；faction_visual、relation_styles 和 territory_style 描述画法，不包含数值/事件/AI/胜负/外交机制。首批 France 1805 为视觉样例，旗帜由几何原语重绘；公开史实参考与地理数据路线见 references。不得把样例当成真实政治边界或现有剧本的改版。

通过条件：声明文件存在、schema/哈希/帧/内存校验通过；在预览中实际可见且锚点、透明边和尺寸稳定。Codex 负责游戏接入及 Android 验收。
